# AsociacionCiguena

Proyecto Android (Kotlin) — descripción corta.

Requisitos:
- Android Studio (última versión estable)
- JDK 17 o 21 (recomendado)
- Gradle wrapper (usa ./gradlew)

Cómo compilar (PowerShell):

    Set-Location -Path 'C:\Users\flori\AndroidStudioProjects\AsociacionCiguena'
    .\gradlew.bat clean assembleDebug

Archivos que no se suben:
- local.properties
- google-services.json
- *.jks / keystore
